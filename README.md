# PromptZero

**Write less. Get more.**

PromptZero is a Jac-powered context compiler that cleans messy AI prompts, protects important requirements, estimates token savings, suggests precise camera vocabulary, and converts text-based PDFs to downloadable Markdown.

## Features

- Jac walker-based prompt analysis
- Prompt cleanup and token estimates
- Meaning Lock for critical requirements
- Intent Graph and Context Diff
- Camera vocabulary assistance
- PDF-to-Markdown conversion
- Safari extension for ChatGPT drafts
- Local processing with no external model calls

## Run locally

```bash
git clone https://github.com/ashamsan21/JACHACKS-PROJECT-FALL-2026.git
cd JACHACKS-PROJECT-FALL-2026
./run.sh
```

Open `http://127.0.0.1:8000`.
